# KB-014: Remote support session checklist (AnyDesk, TeamViewer, Remote Desktop)

**Category:** Process  
**Applies to:** Windows 10 and Windows 11 (menu names can differ slightly)  
**Support level:** L1 (first-line)

## Symptoms

- User needs help but is not at the same location
- Issue is easier to diagnose by seeing the screen

## Possible causes

- Not applicable. This is a procedure, not a fault.

## Steps

1. Confirm the user's identity and that they agree to a remote session. Never connect without consent.
2. Ask the user to open AnyDesk or TeamViewer and share the session ID and the one-time code. For Remote Desktop, use the approved company method and a company-managed account.
3. Tell the user what you will check before you begin, and ask them to close private documents and messages.
4. Reproduce the problem on the user's screen, then apply the fix from the matching article.
5. Do not open personal files, and do not install software that is not approved.
6. Confirm with the user that the issue is resolved, then end the session and ask the user to close the remote tool.
7. Record the issue, steps taken, time spent and outcome in the ticket worklog before closing the ticket.

## Expected result

The user confirms the issue is fixed, the session is closed, and the worklog is complete.

## Escalate to L2 if

The fix needs administrator rights you do not have, or the user's account may be compromised. Escalate to L2.

## Ticket worklog example

> Issue: remote support session checklist (anydesk, teamviewer, remote desktop). Steps taken: see KB-014. Result: ______. Time spent: ____ min. Escalated: Yes / No.
