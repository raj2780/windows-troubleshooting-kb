# Windows Troubleshooting Knowledge Base

A set of 14 first-line (L1) troubleshooting articles for common Windows 10 and 11 problems. Each article lists symptoms, likely causes, step-by-step fixes, the expected result, and when to escalate to L2.

Author: Raj Shukla

## How to use

1. Find the symptom in the index below and open the article.
2. Follow the steps in order, and stop when the issue is fixed.
3. Record what you did in the ticket worklog (each article has an example line).
4. If an escalation condition is met, pass the case to L2 with the steps already tried.

## Article format

Every article uses the same sections: Symptoms, Possible causes, Steps, Expected result, Escalate to L2 if, and a ticket worklog example. See `TEMPLATE.md` to add a new one.

## Notes

- Menu names and paths differ slightly between Windows 10 and 11.
- Commands marked as administrator must be run from a Command Prompt or PowerShell window opened with **Run as administrator**.
- Back up important data before resetting, reinstalling or repairing Windows.
